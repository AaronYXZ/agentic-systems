# Mission: Build Production-Minded AI Agents

## Why

Develop the judgment and hands-on ability to turn existing LLM, RAG, and agent knowledge into reliable agentic software that can be explained, evaluated, and eventually operated in production.

## Success looks like

- Build a useful agent in Python with LangChain and LangGraph.
- Choose and justify agent patterns based on task requirements and failure modes.
- Integrate tools and other agents through MCP and A2A.
- Test state, memory, safety controls, hallucination behavior, and recovery paths.
- Ship a capstone with traces, evaluations, approval gates, and an operational runbook.

## Constraints

- Teach incrementally and require a small working artifact at every stage.
- Assume conceptual familiarity with LLMs, RAG, and agents, but no production agent experience.
- Use Python, LangChain, and LangGraph as the default development stack.
- Prefer understanding and evidence over rapidly accumulating framework features.

## Out of scope

- Training foundation models.
- Comparing every agent framework.
- Large-scale infrastructure before a local, testable design works.

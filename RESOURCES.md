# Agentic Systems Resources

## Knowledge

- [LangChain overview](https://docs.langchain.com/oss/python/langchain/overview)
  Official conceptual and API entry point. Use for models, messages, tools, agents, and structured output.
- [LangGraph overview](https://docs.langchain.com/oss/python/langgraph/overview)
  Official orchestration overview. Use for stateful workflows, durable execution, streaming, and human-in-the-loop control.
- [LangChain and LangGraph learning guides](https://docs.langchain.com/oss/python/learn)
  Official tutorials covering RAG, memory, custom graphs, and multi-agent patterns. Use when starting a roadmap stage.
- [Model Context Protocol specification](https://modelcontextprotocol.io/specification/latest)
  Canonical MCP specification. Use for protocol architecture, lifecycle, primitives, transports, and security requirements.
- [A2A Protocol specification](https://a2a-protocol.org/latest/specification/)
  Canonical A2A specification. Use for agent discovery, tasks, messages, artifacts, transport, and security.
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)
  Risk-management framework for trustworthy AI. Use to structure governance and responsible AI decisions.
- [OWASP Top 10 for Large Language Model Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
  Application-security risk catalog. Use for threat modeling prompt injection, data leakage, excessive agency, and related risks.
- [ReAct paper](https://arxiv.org/abs/2210.03629)
  Primary paper for interleaving reasoning and acting. Use to understand the design pattern beyond framework APIs.
- [Reflexion paper](https://arxiv.org/abs/2303.11366)
  Primary paper on verbal reinforcement and reflective feedback. Use when evaluating reflection loops and their costs.

## Wisdom (Communities)

- [LangChain Forum](https://forum.langchain.com/)
  Framework-focused community. Use for implementation questions after reducing a problem to a reproducible example.
- [MCP GitHub discussions](https://github.com/orgs/modelcontextprotocol/discussions)
  Protocol community discussions. Use for interoperability and specification interpretation questions.
- [A2A GitHub discussions](https://github.com/a2aproject/A2A/discussions)
  Protocol community discussions. Use for cross-framework agent interoperability questions.
